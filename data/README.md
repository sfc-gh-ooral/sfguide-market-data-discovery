# Synthetic data

Everything here is generated by `scripts/generate-data.mjs` with a fixed seed (20261107), so every run produces the same files and the screenshots match what you get. "Acme Market Data" (the vendor) and "Northwind Wealth" (the firm) are fictional. Every issuer, ticker, fund, advisor, and client name is invented. Identifiers in `ISIN_LIKE_ID` use the prefix `ZZ`, which isn't an ISO country code, so they can never match a real ISIN.

Daily prices aren't shipped as a file. `sql/setup.sql` computes them from a closed-form formula (a few sine waves on a drift, per security), and the generator uses the same formula for the no-account mode. `CLOSE_UNADJ` is `CLOSE_ADJ` times every later split ratio.

The no-account mode reads `lib/mock/market.json`, which the same script precomputes from the same data.

## Planted stories

1. **Merger concentration.** Quillfield Semiconductor (QLFD) merges into Arvane Systems (ARVN) on 2026-03-02, at 0.85 ARVN per QLFD share. Many client books held both. Client holdings have two snapshots, 2026-02-27 and 2026-10-30. Between them, Technology goes from 24.8% to 27.6% of client value, ARVN reaches 15.5% of all client value, and accounts above a 10% single-name guideline in ARVN go from 53 to 171.
2. **A split that looks like a crash.** Corvella Therapeutics (CRVL) splits 4-for-1 on 2025-06-16. `CLOSE_UNADJ` falls from 1,155.80 to 294.24 overnight, while `CLOSE_ADJ` is continuous (288.95 to 294.24). `CORPORATE_ACTIONS` explains the gap.
3. **Two similar fields.** `PRICES_DAILY.CLOSE_ADJ` and `CLOSE_UNADJ` have dictionary entries that say when to use each. The agent searches the dictionary and picks `CLOSE_ADJ` for history and charts.
4. **Underused licenses.** In the 90-day usage log, ESG scores ($45K a year) and fund holdings ($31K a year) have 3 and 1 queries, while other datasets have hundreds.

All of these results hold on this synthetic data set only.

To regenerate: `npm run generate-data`.
